# Hints

## General

- Remember that RNA does not contain the nucleotide Thymine (`T`). In RNA, Thymine is replaced by Uracil (`U`).
- A common mistake is producing a DNA complement rather than an RNA complement: DNA Adenine (`A`) transcribes to RNA Uracil (`U`), not Thymine (`T`).
- If your tests fail on `A`, test with the single-nucleotide input `"A"`: the expected RNA output is `"U"`.
